# Chanchal & Shivam — First Anniversary

A self-contained responsive anniversary website for 11 December 2026.

## Netlify
Static site. Leave the build command blank and set the publish directory to `.`.
The nine wedding photos and supplied audio are embedded in `index.html`.

## Includes
- Responsive plum, rose and champagne-gold design
- Nine wedding photos with full-screen lightbox
- User-controlled anniversary music
- Desi sibling-style teasing for Pandit Ji and CA Sahab
- English anniversary letter and interactive final wish
