# SurpriseLink Studio — Celebration Website Template

Private reusable starter for creating bespoke celebration websites. This is a foundation, not a customer-ready published demo.

## Preview
Open `index.html` in a modern browser. No build step or dependencies.

## Adaptation checklist
1. Replace sample copy with customer-approved wording.
2. Select a palette and type direction appropriate to the occasion.
3. Add only customer-approved images and media.
4. Add working contact, RSVP or reveal interactions as required.
5. Test responsive layouts, accessibility and every link.
6. Obtain customer approval before public deployment.

## Included
- Responsive starter layout
- Opening, story/features and personalisation sections
- Adaptable colour tokens and CSS styling
- Netlify-ready static configuration

Keep this repository private; create a separate customer-specific repository for each delivered website.
